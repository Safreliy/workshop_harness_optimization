Название отчёта, формулы показателей, группировка строк, фильтры, часовой пояс, формат и открытые вопросы.

→
3 · ПРЕДЛОЖЕНИЕНовый SQL и индекс

Фильтр по диапазону времени позволяет использовать индекс. Агент проверяет вариант внутри временной транзакции.

→
4 · АВТОМАТИЧЕСКАЯ ПРОВЕРКАРезультаты совпадают, стоимость плана ниже

Проверка также детерминирована:SQL остаётся только для чтения, результат совпадает, индекс откатывается, отношение стоимости плана превышает заданный порог.
