# ДЗ: улучшить ETL-агента

**Распакуйте весь архив → откройте [etl_homework.ipynb](etl_homework.ipynb) в JupyterLab или VS Code → Run All.** Нужны Python 3.11+ и Jupyter с Python-ядром. Браузер сам не исполняет `.ipynb`.

Агент строит сверенную таблицу из заказов, платежей и возвратов. Вы изменяете один механизм и проверяете качество, расходы и регрессии. Постановка и ожидаемый результат описаны до первого запуска кода.

Первый проход не требует API и показывает ошибку 6930 вместо 6153. Выполните упражнение с `QUERY` и `FILTER`, затем перенесите найденное общее правило в конфиг кандидата.

## Всё через ноутбук

1. Для сохранения кандидата и новых ответов агента один раз выполните первую ячейку с `INSTALL_DEPS=True`, затем верните `False`. Зависимости устанавливаются в текущее ядро.
2. Измените `CHANGES`, опишите гипотезу и включите `SAVE_CANDIDATE` для сохранения. Контроль и ваша предыдущая правка не сбрасываются при Run All.
3. Укажите `BASE_URL`, `MODEL` и включите `CONNECT`. Ключ вводится через скрытый запрос и остаётся в памяти. Proxy и CA необязательны.
4. В ячейке эксперимента включите `RUN_LIVE=True`. Повторяйте только её с `ACTION`: **smoke → train → dev → select → test**. Выбор и копии конфигов фиксируются автоматически до test.

Данные: 24 train / 12 dev / 12 test. Короткая проверка — 6 платных эпизодов; полный цикл — ещё 96. Вызовов модели может быть больше. Имя `EXPERIMENT` связывает серию с конкретными моделью, конфигами, кодом и данными. Изменили условия или хотите повтор — новое имя. Изменили Python-код — также перезапустите ядро.

Если контроль уже проходит 100%, проверяйте снижение вызовов/токенов при сохранении качества на повторных сериях. Небольшая разница одного прогона ещё не доказывает эффект; отрицательный и нулевой результаты допустимы.

Сдайте гипотезу, контрпример, diff, конфиги и папку результатов. Если API недоступен, отметьте, что эффект на новых ответах агента не измерен. LangGraph/LangChain допустимы при сохранении входов, журнала, итогового артефакта и независимой проверки.

`build.py` и `notebook_template.py` используются ведущим для пересборки; для ДЗ они не нужны.
