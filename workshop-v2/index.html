Кто создаёт ledger, что остаётся от task и как работает _clip?
agent.py:77–108. Отдельный _call с ledger_prompt получает полный dialogue. Код вставляет текст ответа и 4 последних source turns; затем render_task добавляет название задачи и REPORT_CONTRACT. JSON ledger запрашивается в prompt; отдельной проверки его схемы здесь нет. Объект case остаётся в Python; для LLM задача, контракт и ledger собраны в одну строку user-сообщения, отдельного защищённого блока задачи нет.
if report and context_strategy == "requirements_ledger":
    ledger_turn = self._call(..., ledger_prompt(case), config)
    context_override = ledger_turn.content + latest_source_turns[-4:]

task_text = self._clip(
    render_task(case, context_override), max_context_chars

Это сокращённый порядок кода. У SQL нет этого ledger-вызова: он получает question, исходный SQL и SQL_CONTRACT.
prompts.py:93. Ledger prompt просит поля active_requirements, superseded_requirements, unavailable_data, open_questions, provenance. Актуальное требование должно ссылаться на последнюю установившую его реплику.
def _clip(text, max_chars):
    if len(text) <= max_chars:
        return text
    head = max_chars // 3
    tail = max_chars - head
    return (text[:head]
        + "[... context clipped by harness ...]"
        + text[-tail:])
Это обрезка строкой по символам, без вызова LLM. Сохраняются начало и конец; середина task_text может потеряться. Граница не ограничивает system, tools или последующие сообщения.
Краткая история сохраняет ход работы. Состояние задачи хранит действующие условия, решения и следующий шаг.

CURRENCY CHECK: Before summing payments/refunds, normalize and compare each event currency with the currency of its latest order. Unknown/orphan and mismatched currencies must not contribute. A WHERE filtering only settled/non-null amounts does NOT enforce currency equality. When an aggregate differs from your manual expectation, query the exact contributing rows under that same WHERE before rerunning SUM or suspecting the SQL engine. Apply the currency condition for every order, not a literal USD.
